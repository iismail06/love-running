# Love Running

Love Running is a fictional website for a running club. This README provides an overview of the project, including a wireframe section to visualize the website's structure.

## Table of Contents

- [Project Overview](#project-overview)
- [Wireframes](#wireframes)
- [Technologies Used](#technologies-used)
- [Credits](#credits)

## Project Overview

Love Running is designed to encourage people to join a running community, share experiences, and sign up for events. The site includes a homepage, gallery, and signup page.
