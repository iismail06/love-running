# Love Running

## Project Overview

Love Running is designed to encourage people to join a running community, share experiences, and sign up for events. The site includes:

- **Homepage:** Hero section with call-to-action, reasons to join, event calendar, interactive map, and meetup times.
- **Gallery:** Photo gallery with lightbox effect for viewing images.
- **Signup:** Newsletter modal and dedicated signup page for new members.

The website is fully responsive, accessible, and visually modern, with features to enhance user engagement and experience.

## Technologies Used

- HTML5
- CSS3
- JavaScript (for modals, lightbox, and interactivity)
- Font Awesome (icons)

## Features

- **Hero Section:** Eye-catching image, club slogan, and "Join Now" button.
- **Reasons to Join:** Highlights health, strength, freedom, and social benefits with icons.
- **Event Calendar:** Table of upcoming runs and social events.
- **Interactive Map:** Embedded Google Map showing meetup locations in Dublin.
- **Meetup Times:** Weekly schedule for urban, trail, and social runs.
- **Photo Gallery:** Clickable images open in a lightbox modal for larger view.
- **Newsletter Signup:** Accessible modal for collecting emails.
- **Footer:** Social links (LinkedIn, GitHub), copyright, and responsive design.

## Accessibility

- All images have descriptive alt text.
- Keyboard navigation supported for modals and gallery.
- Sufficient color contrast and clear focus indicators.
- ARIA labels and roles for improved screen reader support.
- Form fields use appropriate labels and autocomplete attributes.

## Deployment

This project is static and can be deployed on GitHub Pages, Netlify, or any static hosting provider.
To deploy on GitHub Pages:

1. Push the repository to GitHub.
2. Go to the repository settings > Pages.
3. Select the main branch and `/ (root)` folder.
4. Save and access your site at the provided URL.

## Testing

- Manual testing on Chrome, Firefox, Safari, and mobile browsers.
- Lighthouse used for accessibility and performance checks.
- All interactive features (modals, lightbox, navigation) tested for keyboard and screen reader accessibility.

## Usage

1. Clone or download the repository.
2. Open `index.html` in your browser.
3. Explore the homepage, gallery, and signup features.
